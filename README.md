# Ana Bus

**Ana bus bi ?** Ana Bus montre où se trouve votre bus à Dakar et dans combien de minutes il arrive à votre arrêt. Tapez le numéro de la ligne, voyez le bus sur la carte.

*bul xaar ba sonn*

Un projet porté par Mouhamed Abdallah Lo et Seyda Mariama Wade.

## Où en est le projet

La marque, la charte et les maquettes sont prêtes. Le code de l'application n'est pas encore écrit : c'est l'étape suivante.

| Dossier | Contenu |
| --- | --- |
| `docs/` | Le dossier de projet, la charte de marque et la description de chaque écran |
| `design/` | Variables de design, polices, logos, pictos, mascotte Kaay, composants de référence |
| `maquettes/` | Les images et pages HTML de référence de chaque écran |
| `CLAUDE.md` | Le contexte du projet pour Claude Code |
| `PROMPT.md` | Le message qui lance la construction de l'application |

## Lancer la construction

1. Ouvrez Claude Code sur claude.ai/code et choisissez ce dépôt.
2. Copiez tout le texte de `PROMPT.md` et envoyez-le.

Claude Code lit le kit, propose un plan et attend votre accord avant d'écrire le code. Il livre ensuite en 6 étapes, en s'arrêtant après chacune pour que vous testiez.

Toutes les lignes, arrêts et temps des maquettes sont des exemples fictifs.
