# Données de démonstration

**Tout ici est fictif.** Les noms de quartiers de Dakar sont réels ; les numéros de ligne, les
tracés, l'ordre des arrêts, les coordonnées exactes, le nombre de bus, les vitesses et les
retards sont inventés pour le prototype. Tant que ces données servent, l'appli affiche le
bandeau « Démo : données fictives ».
