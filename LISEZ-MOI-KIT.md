# Kit Ana Bus pour Claude Code

Ce kit contient tout ce dont Claude Code a besoin pour construire Ana Bus : le contexte du projet, la charte, les maquettes de chaque écran et les fichiers officiels de la marque.

## Comment l'utiliser

1. Sur github.com, créez un dépôt, par exemple `ana-bus`. S'il est public, le site pourra être mis en ligne gratuitement sur GitHub Pages ; s'il est privé, Claude Code proposera Netlify ou Vercel.
2. Déposez-y le fichier `ana-bus-kit.zip` (Add file, puis Upload files). Inutile de le décompresser.
3. Ouvrez Claude Code (claude.ai/code) et choisissez ce dépôt.
4. Copiez tout le texte de `PROMPT.md` et envoyez-le.

Claude Code décompresse le kit, lit le contexte, puis vous propose un plan avant d'écrire la moindre ligne de code. Il livre ensuite en 6 étapes, en s'arrêtant après chacune pour que vous testiez.

## Contenu

| Élément | Rôle |
| --- | --- |
| `PROMPT.md` | Le message à envoyer à Claude Code |
| `CLAUDE.md` | Le contexte permanent du projet, relu par Claude Code à chaque session |
| `docs/projet.md` | Le dossier de projet résumé |
| `docs/charte.md` | La charte de marque |
| `docs/ecrans.md` | La description de chaque écran, avec les textes exacts |
| `design/` | Variables de design, polices, logos, pictos, mascotte Kaay, composants de référence |
| `maquettes/png/` | Les images de référence de chaque écran |
| `maquettes/html/` | Les mêmes maquettes, à ouvrir dans un navigateur |

Toutes les lignes, arrêts et temps des maquettes sont des exemples fictifs.
